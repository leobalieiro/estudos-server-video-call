**Detalhes:** 

Sistema de websocket para comunicação de protocolos WebRTC pronto para você realizar chamadas de vídeo como os servidores iceServers configurados para fazer vídeos-chamadas fora da sua rede local, simples e leve com sistema de salas(rooms) já integrado, para formato 1x1 para vídeo-chamada ideal para sistema de consultas via video-chamada a base é sólida.


**Inicialização:**

>  docker compose up --build



**Front-end:**

> http://localhost:3001



**Back-end:**

> ws://localhost:3001
